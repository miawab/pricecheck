# payproof

Check whether a payment screenshot (JazzCash, Easypaisa, NayaPay, SadaPay) is real before you hand over the item.

Built for the [Hacktoberfest 2026 DEV Challenge, Week 2: Side Hustle](https://dev.to/challenges/hacktoberfest-week2-2026-10-12).
Open-weight models only, runs locally, free.
